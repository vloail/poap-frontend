Current Project:
POAP Attendance — On-chain Proof of Attendance Protocol

Features:
- Wallet Login (MetaMask)
- Mint Free POAP NFT with Your Name
- 100% On-chain Metadata & SVG Image (no IPFS needed)
- One POAP Per Address (anti-sybil)
- Attendee Leaderboard
- Responsive Dark Mode UI

Technology Stack:
- Solidity + Foundry + OpenZeppelin ERC-721
- React + TypeScript + Tailwind CSS
- wagmi + viem
- GIWA Testnet (Chain ID: 91342)

Why This Matters:
POAP Attendance solves a real problem for event organizers — a simple, gas-efficient way to issue proof of attendance that works entirely on-chain. Attendees just connect their wallet, type their name, and mint. No external storage, no complex setup.
